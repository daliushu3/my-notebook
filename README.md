# 📝 我的笔记应用 - 使用说明

## 🎯 版本说明

- ✅ 在线使用，无需安装
- ✅ 存储空间更大（几百MB到几GB）
- ✅ 自动图片压缩功能
- ✅ 实时显示存储空间使用情况
- ## ✨ 新功能说明

### 1. 图片自动压缩
- 上传图片时自动压缩到合理大小
- 最大宽度/高度：1920px
- 压缩质量：80%（图集）、90%（头像）、85%（壁纸）
- 大幅减少存储空间占用

### 2. 存储空间监控
- 实时显示已使用和总配额
- 帮助你了解数据占用情况
- ## ⚠️ 注意事项

1. **IndexedDB版本**
   - 每个浏览器独立存储（Chrome的数据和Edge不共享）
   - 清除浏览器数据会删除笔记
   - 建议定期导出备份

2. **图片存储**
   - 所有版本都将图片转换为base64存储
   - 虽然有压缩，但大量高清图片仍会占用较多空间
   - 建议：
     - 图集内容优先使用外部图床链接
     - 重要图片才存储在应用内

## 🆘 常见问题

**Q: 提示存储配额不足？**
- A: 可能是浏览器限制，尝试：清理浏览器缓存（保留站点数据）

**Q: 数据文件在哪里？**
- A: 在浏览器内部数据库，通过导出功能获取

**Q: 如何完全卸载？**
- A: 清除浏览器站点数据
